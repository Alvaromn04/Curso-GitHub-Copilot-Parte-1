# Initiation Process

The Initiation phase validates that a proposed effort should move forward.

## Objectives

- Define the problem statement and expected business outcome.
- Identify stakeholders, owners, and decision-makers.
- Draft and align on a lightweight project one-pager.

## Core Activities

1. Confirm project scope and success metrics.
2. Identify dependencies, assumptions, and high-level risks.
3. Secure approval to move into Planning.

## Exit Criteria

- Project one-pager approved.
- Stakeholder map and ownership confirmed.
- Initial risks captured in the Risk Register.
